# Event-aware diagnostic benchmark results v0.3

The [frozen protocol](protocol-v0.3.md) was executed without threshold changes.
The deterministic full output is generated by
`uv run python scripts/run_benchmark_v3.py`; compact results are in
[`results-v0.3.json`](results-v0.3.json).

Two of four criteria passed:

- `event_correlated_reference` detected event-locked motion in 20/20 runs;
- it also detected reference contamination in 20/20 runs;
- `signal_reference_lag` detected only 8/20 lagged-reference runs, failing the
  18/20 requirement;
- the lag warning also appeared in 8/20 clean runs, failing the ≤2/20 false
  warning requirement.

The event-response diagnostic repairs the specific v0.2 blind spot: it exposes
when the reference itself changes around the tested events. Its interpretation
remains deliberately neutral because the response could be motion, neural
contamination, haemodynamics, or another event-correlated process.

The derivative lag scan is retained as an experimental metric but its warning is
not suitable for decision-making. At this signal-to-noise ratio, differentiation
amplifies independent measurement noise and a broad lag search selects spurious
maxima. A future protocol should compare pre-specified smoothing, band-limited
cross-correlation, and out-of-sample lag models.
