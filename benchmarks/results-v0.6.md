# Extended scalar-calibration results v0.6

The [frozen protocol](protocol-v0.6.md) evaluated 5,000 simulated studies using
500 stratified animal-bootstrap draws each. Full deterministic output is
generated by `uv run python scripts/run_extended_calibration.py`; compact ranges
are in [`results-v0.6.json`](results-v0.6.json).

All four acceptance criteria failed. Across Gaussian, Student-t,
heteroscedastic, unequal-event-count, and informative-missingness scenarios:

- percentile coverage was 87.8–88.6%;
- basic coverage was 87.6–88.8%;
- BCa coverage was 87.4–89.0%;
- power for an effect of 0.8 animal SD was only 35.2–39.2%;
- median interval widths were approximately 1.94–2.00 animal SD.

No interval method is default-eligible. The near-identical outcomes show that
changing bootstrap interval formulas does not repair the finite-sample problem
with six animals per group. This larger benchmark supersedes the optimistic
impression from the coarse v0.5 grid while preserving those earlier results.

The informative-missingness simulation also cannot validate ignorability: its
measurement process changes the observed estimand. Future work must distinguish
recovery of the complete-data effect from inference about the observed-data
effect rather than describing either as generic “coverage.”
